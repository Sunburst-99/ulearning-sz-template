# ulearning-sz-template

思政前端项目

## Node Version

```sh
"^20.19.0 || >=22.12.0"
```

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check

```sh
npm run typecheck
```

### Compile and Minify for Production

```sh
测试环境：npm run build:test
生产环境：npm run build
```
