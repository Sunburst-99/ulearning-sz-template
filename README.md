# ulearning-sz-template

思政自定义Vue3+TS+Vite脚手架预设

## Node Version

```sh
"^20.19.0 || >=22.12.0"
```

## Project Setup

```sh
vue create [项目名称] -p Sunburst-99/ulearning-sz-template
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
测试环境：npm run build:test
生产环境：npm run build
```
